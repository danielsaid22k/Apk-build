CCS v6.0.1 — CORREÇÃO PHANTOM

1. Execute INSTALL_WINDOWS.bat se for uma instalação nova.
2. Configure Telegram e carteiras.
3. Execute START_WINDOWS.bat.
4. Aguarde aparecer “URL pública configurada”.
5. No Telegram, toque em “Reenviar pendentes” para gerar botões com a URL nova.

IMPORTANTE:
- Mensagens antigas do Telegram continuam contendo URLs antigas.
- Sempre use o cartão reenviado depois que o Quick Tunnel iniciar.
- Não feche a janela do START_WINDOWS.bat.
